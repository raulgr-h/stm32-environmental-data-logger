# STM32L431 Environmental Data Logger

A custom embedded data logger built around the STM32L431 microcontroller. The system measures temperature and relative humidity using an SHT41 sensor over I2C and records measurements to a microSD card over SPI using FatFs.

The project includes a custom KiCad PCB, STM32CubeIDE firmware, hardware bring-up documentation, measurement captures, verification results, and manufacturing files.
